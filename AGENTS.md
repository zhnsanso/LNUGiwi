# AGENTS.md

GiWiFi campus-network auth tool for 岭南师范学院 (Lingnan Normal University). UI strings, docs, and comments are in Chinese — keep new user-facing text and README content in Chinese.

## Single Flutter implementation

One Flutter codebase at repo root (`lib/`, `android/`, `ios/`, `macos/`, `windows/`) for all platforms. Dart SDK ^3.5.0, minimal deps (`path_provider`, `url_launcher`). The former C# `windows-lite/` port was removed in v2.0.0; do not reintroduce it — extend the Dart code instead. Both implementations read/wrote the same `%APPDATA%\giwifi_ua_switcher\settings.json`, which is why migration was seamless.

## Auth/crypto logic exists in two places that must stay in sync

- `lib/utils/aes_crypto.dart` — hand-rolled AES-128-CBC, no crypto package. Do not replace with a dependency without syncing the vectors.
- `tool/gen_test_vectors.py` (pycryptodome) — reference implementation that generates `tool/vectors.json`; its outputs are baked into `test/auth_flow_test.dart`, `test/aes_crypto_test.dart`, and `tool/selfcheck.dart` as expected ciphertexts.

Changing form-building, padding, or encryption requires updating the other place and the test vectors, or the 对拍 (cross-check) tests fail.

Crypto quirks: CryptoJS-compatible ZeroPadding (no extra pad block when plaintext is already 16-byte aligned); key is the hardcoded constant `kGiWifiAesKey` = `1234567887654321`; IV comes from the portal page's hidden `iv` field.

## Commands

```bash
flutter pub get
flutter analyze                 # only rule: prefer_const_constructors; tool/** is excluded
flutter test                    # all tests
flutter test test/aes_crypto_test.dart   # single file
flutter test --update-goldens   # only after intentional UI changes
dart run tool/selfcheck.dart    # standalone self-check, no packages needed
```

Run `flutter analyze` and `flutter test` before pushing — release CI only packages builds.

## Testing quirks

- Golden tests (`test/screenshot_test.dart`) render with subset fonts in `test/fonts/`, generated by `tool/make_test_fonts.py` (needs `fonttools`, downloads Noto Sans SC) from the characters/icons actually used in `lib/`. Adding new UI strings or icons requires regenerating test fonts (`--icons-only` for icons), or goldens render fallback glyphs.
- Widget tests must set `SettingsService.configDirOverride` to a temp dir — otherwise tests read/write the real config at `%APPDATA%\giwifi_ua_switcher` on Windows.
- Auth-flow tests are pure Dart crypto/form tests against fixed vectors; no network or mocks involved.

## Storage

Settings and logs go to `%APPDATA%\giwifi_ua_switcher` on Windows (other platforms: path_provider support dir). Credentials are stored in plaintext when "记住账号密码" is enabled — never commit real accounts, passwords, or captured portal data.

## Release

`.github/workflows/apple.yml` (iOS + macOS + Windows builds) runs on manual dispatch or pushing a `v*` tag; the release job publishes a GitHub Release with all artifacts. First Windows CI build is unverified — prefer a `workflow_dispatch` dry run before tagging.

Release order — the version in `pubspec.yaml` must match the tag or the release ships a mismatched internal version (this bit v1.1.6):

1. Bump `version:` in `pubspec.yaml` (build number is date-based, e.g. `2.0.0+2026110801`)
2. Commit the bump
3. Tag: `git tag v2.0.0`
4. Push tag **by name**: `git push origin v2.0.0` — tags here are lightweight, and `--follow-tags` pushes annotated tags only, so it would silently skip the tag and the release never fires

## tool/ scripts (Python, dev-only)

- `make_app_icons.py` (`pillow`) — regenerates all platform app icons from one master drawing.
- `make_test_fonts.py` (`fonttools`) — see testing quirks above.
- `gen_test_vectors.py` (`pycryptodome`) — regenerates AES test vectors.
